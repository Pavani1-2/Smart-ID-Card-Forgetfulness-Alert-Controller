# Physical design notes

This folder is a starting point for OpenROAD-flow-scripts (ORFS), not a claim of completed physical implementation.

1. Install/clone a compatible OpenROAD-flow-scripts version and set up a supported PDK platform (e.g. SKY130 HD).
2. Check the platform's synthesis, LEF, Liberty, RC, and GDS configuration.
3. Copy/adapt `openroad_config.mk.example` into the directory/filename expected by your ORFS version.
4. Confirm the top module is `smart_id_alert_controller` and that the RTL and SDC paths resolve.
5. Run the flow using the documented command for your ORFS checkout.
6. Inspect the run logs and final timing reports; do not assume success from the presence of a config file.
7. Use the actual final GDS path printed/generated by the flow. Verify it opens in KLayout and run the checks supported by the selected PDK.

The sample die/core dimensions are placeholders. A tiny RTL design may require a much smaller floorplan; choose dimensions based on cell area, utilization, pin plan, and the selected flow. DRC/LVS signoff depends on the selected PDK tools and setup.
