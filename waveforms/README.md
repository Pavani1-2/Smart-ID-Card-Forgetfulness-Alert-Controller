# Waveforms
`illustrative_functional_trace.vcd` is a small illustrative VCD trace showing a clock, reset, door/card inputs, and alert outputs. It is provided to demonstrate the VCD format and signal naming; it is not a substitute for the authoritative waveform generated by running `./sim/run_iverilog.sh`.
